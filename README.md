## Установка

1. Откройте [последний релиз](https://github.com/letohq/Leto-Desktop/releases/latest) и скачайте `LETO-Windows-x64-<версия>.zip`.
2. Полностью распакуйте папку `LETO` в удобное место.
3. Запустите `LETO.exe` и подтвердите запрос прав администратора.

Не отделяйте `LETO.exe` от папок `app` и `runtime`. Ссылки GitHub `Source code` не являются приложением.

## Возможности

- VPN-подключение в один клик на базе Xray.
- Автоматический и ручной выбор сервера.
- Полный VPN и отдельный режим маршрутизации приложений и сайтов.
- Kill Switch, автозапуск и обновление внутри приложения.

## Требования

Windows 10 или Windows 11 x64, около 300 МБ свободного места и права администратора. Java устанавливать не нужно.

> Windows может показать SmartScreen, поскольку приложение пока распространяется без цифровой подписи издателя.
