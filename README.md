# LETO VPN для Windows

Быстрый и простой VPN-клиент для Windows. Одна кнопка — и соединение защищено.

[**⬇ Скачать последнюю версию**](https://github.com/letohq/Leto-Desktop/releases/latest)

---

## Возможности

- **Подключение в один клик** — выбираете сервер и нажимаете «Подключить».
- **Выбор страны** — список доступных локаций с индикацией скорости отклика.
- **Раздельное туннелирование** — можно направить через VPN только нужные
  приложения или сайты, а остальной трафик оставить напрямую.
- **Kill Switch** — если соединение с VPN внезапно прервётся, интернет-трафик
  будет заблокирован, чтобы ваш реальный IP-адрес не раскрылся.
- **Автозапуск** — приложение может стартовать вместе с Windows и работать в
  системном трее.
- **Автоматические обновления** — новые версии устанавливаются из приложения.

## Установка

1. Скачайте `LETO-Setup-<версия>.exe` со [страницы релизов](https://github.com/letohq/Leto-Desktop/releases/latest).
2. Запустите установщик и следуйте подсказкам мастера.
3. Подтвердите запрос прав администратора — они нужны, чтобы создать сетевой
   адаптер и настроить маршруты. Без этого VPN не сможет работать.
4. Войдите в приложение по e-mail или через Telegram.

### При установке появится предупреждение Windows

Приложение пока распространяется без цифровой подписи издателя, поэтому Windows
SmartScreen покажет уведомление «Windows защитила ваш компьютер», а в окне
запроса прав издатель будет указан как неизвестный.

Чтобы продолжить установку: нажмите **«Подробнее»** → **«Выполнить в любом
случае»**.

Если хотите убедиться, что файл скачался целиком и без изменений, сверьте его
контрольную сумму с той, что указана на странице релиза:

```powershell
Get-FileHash .\LETO-Setup-1.0.0.exe -Algorithm SHA256
```

## Системные требования

| | |
|---|---|
| Операционная система | Windows 10 или Windows 11, 64-разрядная |
| Свободное место | около 300 МБ |
| Права | администратор (запрашиваются при установке и запуске) |

Устанавливать Java или другие компоненты не нужно — всё необходимое уже входит
в состав установщика.

## Обновление и удаление

**Обновление.** Приложение само проверяет наличие новых версий и предложит
обновиться. Можно также скачать свежий установщик отсюда и запустить поверх —
настройки и вход сохранятся.

**Удаление.** «Параметры» → «Приложения» → «LETO VPN» → «Удалить». Либо через
меню «Пуск» → папка «LETO VPN» → «Удалить LETO VPN».
